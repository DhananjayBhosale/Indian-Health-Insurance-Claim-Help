# Security and privacy

Health claims contain medical, identity, financial, and insurance data. Treat every real case as private.

- Keep case workspaces outside this repository.
- Do not commit, attach to an issue, or paste into logs any real PDF, image, manifest, render, policy/claim number, bank detail, address, diagnosis, prescription, or receipt.
- Run OCR and PDF processing locally unless the claimant explicitly authorizes a named external service.
- Preserve original hashes and restrict access to the private case directory.
- Remove temporary renders after the claimant no longer needs them, following their retention instructions.

Report code vulnerabilities through a private GitHub security advisory when the repository supports it. Do not demonstrate a vulnerability with real claimant data.
